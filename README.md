# Hypnos

Logiciel de gestion hôtelière + système de réservation en ligne pour l'Hôtel Céleste (Brazzaville).

> Projet en développement — usage interne.

## Stack

- **Backend** : Django REST Framework
- **Desktop** : Electron + React
- **Website** : React

## Structure

```
hypnos/
├── backend/api/           # API Django
├── frontend/app/          # Ressources partagées
├── frontend/desktop/      # App Electron
└── frontend/website/      # Site de réservation
```

## Fonctionnalités (MVP)

- Gestion des chambres et réservations
- Réservation en ligne sans création de compte
- Notifications et emails automatiques
- Gestion du personnel
