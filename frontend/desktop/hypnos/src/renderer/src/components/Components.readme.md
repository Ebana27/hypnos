### Guide du Répertoire Components

Ce dossier regroupe l'ensemble des composants réutilisables de l'application. L'objectif est de centraliser les éléments d'interface afin de garantir une cohérence visuelle et de faciliter la maintenance du code.

- **Composants à la racine** : Vous y trouverez les composants métier spécifiques (ou "extra-composants"). Ce sont des éléments complexes, originaux ou étroitement liés aux fonctionnalités uniques de ce logiciel.

- **Dossier "base"** : Ce répertoire contient les composants fondamentaux (atomes). Il s'agit des briques élémentaires indispensables à toute application desktop ou plateforme web (boutons, inputs, modales, icônes, etc.). Ils sont conçus pour être génériques et hautement configurables.
